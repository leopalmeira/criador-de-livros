# REGRAS DO PROJETO CRIADOR DE LIVROS

1. **NUNCA TESTAR NO NAVEGADOR**: É terminantemente proibido abrir subagente de navegador ou navegar na aplicação em background ou fazer requisições que disparem geração e gastem créditos da API de IA do usuário.
2. **PROTEÇÃO DE CRÉDITOS**: Os créditos da API são reais e limitados (inseridos pelo usuário no Google AI Studio). Nenhuma chamada de teste que consuma tokens de geração deve ser feita sem comando manual e explícito do usuário.
3. **COMMITS DIRETOS**: Sempre manter o repositório sincronizado com o Git sem alterações desnecessárias.
